Чтобы запустить квест, нужно запустить файл "quest".
В коде не используются сторонние библиотеки, которые надо загружать отдельно.
Используются только встроенные библиотеки.

Этот квест имеет 3 основные локации: улица, поляна и замок. Ты должен(а) пройти в замок и отгадать 5 загадок стражника. БУДЬ ОСТОРОЖНЕЕ, ты можешь умереть.
